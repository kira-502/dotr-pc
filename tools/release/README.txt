Yu-Gi-Oh! The Duelists of the Roses - PC version

You need your own copy of the game: this program contains no game pictures, sound, movies or data. It plays
the game from a disc image (.iso file) of YOUR OWN disc, the USA version (SLUS-20515). Only use a disc image
made from a game you own.

How to start
  1. Put your disc image (.iso file) of the USA game in this folder, next to
     "Yu-Gi-Oh! The Duelists of the Roses.exe". Any file name is fine.
  2. Double-click "Yu-Gi-Oh! The Duelists of the Roses.exe". The game opens in a window.
  If the disc image is somewhere else, the program asks you to choose it once and remembers it.

Controls
  Xbox controller: works as a PS2 pad (A = Cross, B = Circle, X = Square, Y = Triangle, Start, Back = Select).
  Keyboard (the game window must be in front): arrows, Z = Cross, X = Circle, A = Square, S = Triangle,
    Q / W = L1 / R1, E / R = L2 / R2, Enter = Start, right Shift = Select.
  In a duel: Circle opens your hand, Cross selects and confirms, Start ends your turn.
  Fast-forward: HOLD Tab, or hold the controller's right stick to the right. The game runs several times
    faster while you hold it (sound may skip). Let go for normal speed.
  Alt+Enter or F11: full screen on and off.
  F12 (or push the controller's right stick to the LEFT): "something looks wrong here". See "Reporting a
    problem" below.
  Close the window to quit.

Reporting a problem
  When something looks wrong, press F12 (or push the right stick LEFT) right away. A folder appears in
  "Reports" in this folder, with a picture and what the game was doing in the last minute. Send that folder to
  whoever gave you the game. If the game crashes or freezes, it makes such a folder by itself.
  Every session also keeps its log in the "Logs" folder (the last 20).

If Windows will not start the game
  The game is not signed by a publisher, so Windows may warn about it.
  - "Windows protected your PC": click "More info", then "Run anyway".
  - "An Application Control policy has blocked this file" (Smart App Control): Windows lets an unsigned program
    run only with Smart App Control off (Windows Security > App & browser control > Smart App Control settings).
    Only do this if you trust where you got the game; Windows may not let you switch it back on afterwards.

Saves
  Your memory card is the folder Saves\card1 in this folder. Keep it when you move the game.

If the picture looks wrong or the game does not start
  The game is drawn by your graphics card. To use the slower drawing that does not need the graphics card,
  make a text file called DotR-PC.ini in this folder with this line in it:
      renderer=exact
  If the game stops with a problem, a message tells you; the details are in DotR-PC.log in this folder and in a
  folder in "Reports".

Nothing is installed: delete the folder to remove the game.
